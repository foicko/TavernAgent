# 安装、配置与维护

## 安装与启动

下载与系统匹配的压缩包，核对 `SHA256SUMS.txt`，解压到可写目录。Windows 运行 `tavernagent.exe`；macOS、Linux 运行 `./tavernagent`。浏览器访问 `http://127.0.0.1:8890`。`-version` 显示版本、Git 标识与构建时间；同目录的 `BUILD-INFO.json` 记录源码指纹、前端指纹（构建时 `web/dist` 目录内容的哈希）与前端文件数。

```sh
./tavernagent -data ./data -addr 127.0.0.1:8890
```

Windows PowerShell 使用 `./tavernagent.exe`。macOS 构建未签名、未公证，按系统提示检查下载来源并允许运行；项目不会提供关闭系统安全功能的脚本。数据目录默认相对当前工作目录，长期使用建议传入绝对 `-data` 路径。

## 模型设置

配置只有两层，都在设置页（顶栏模型胶囊 / 输入台模型控件）里完成：

1. **连接**：「＋ 新建连接」→ 先选服务商预设（DeepSeek / OpenAI / Anthropic / 本地 Ollama / 本地 OneAPI / 自定义，会预填协议与地址并给出默认名称）→ 填模型名与 API Key 即可保存。名称与协议也可以改。**生成参数常显**：上下文窗口、最大输出、温度、思考强度，窗口下面直接标出派生出的输入预算（`窗口 − 最大输出 − 安全余量`）。地址只需填到版本根（如 `https://api.deepseek.com`），程序会自动补全具体路径。
2. **角色**：对话生成、导演协商、后台记忆各选一条连接；后两者留空即「跟随对话生成」，也可以单独指定；后台记忆可以整体关闭（关闭后不做后台抽取与摘要维护）。

三个角色共用同一份连接列表：改连接（换模型名、换地址、调窗口、调思考强度）三处一起生效。**删除仍被角色使用的连接会被拒绝**（按钮就地禁用并说明是哪一行在用），先在角色里换一条再删。旧的「模型档案」与槽位内联写法已移除：启动时会把旧配置一次性迁移成连接+引用，迁移前把原文备份为 `data/config/settings.json.v1.bak`（只写一次，回滚旧版本时用它）。

**在输入台换主线**：右下角模型控件显示当前生效的连接名，点开即可换——只影响下一回合，正在生成的这一段保持原连接；切换失败会明确报错。它左边的**思考强度**控件（默认 / 低 / 中 / 高）同理：改的是这条主线连接上的参数，保存后从下一回合生效；`默认` 表示不发送任何思考参数（与旧行为一致），`低 / 中 / 高` 按协议换算成 `reasoning.effort` / `reasoning_effort` / Anthropic extended thinking 预算。上下文仪表在这些控件左侧，是上下文占用百分比，点击可看构成明细；窄屏下控制条换行且仪表隐藏，以保证发送按钮始终可见。

测试连接：连接表单里的「测试连接」只测这一条连接（地址+密钥+模型）是否可达，与它有没有被指派给角色无关，也不会发起生成。

输入预算会预留输出与安全余量；必要状态放不进时会明确报错，可增大窗口、减少输出预留或缩短输入与大纲。

密钥保存在 `data/config/secrets.json`；设置页只显示脱敏值，留空或回传掩码都表示保留原密钥。也可用环境变量覆盖：`TAVERNAGENT_KEY_MODEL_<实例ID>`（实例级，优先）或 `TAVERNAGENT_KEY_PRIMARY` / `_ASSIST` / `_REFLECTION`（槽位级）。不要把密钥写进脚本或命令行参数。

未配置真实供应商时不会调用外部模型。开发体验可用 `-provider mock`；该脚本供应商仅验证应用流程。

## 局域网

启动时传入 `-addr 0.0.0.0:8890`。同一可信局域网的设备打开主机私有 IP 地址，输入启动日志中的六位配对码。重启后配对令牌失效。防火墙仅向可信私有网络开放此端口，勿映射到公网。

浏览器写请求仅接受同源地址。开发代理可以显式设置 `-allow-origin http://localhost:5173`；多个来源用逗号分隔，不能使用通配符。服务不支持公网多租户部署、用户账户或租户隔离。

### 加密传输（HTTPS）

明文 HTTP 在公共或不可信局域网里会把正文与配对令牌摊开给同网段的人。加一个 `-tls` 即可：

```powershell
tavernagent.exe -addr 0.0.0.0:8890 -tls auto     # 自签证书，落在 <数据目录>/tls/
tavernagent.exe -tls files -tls-cert cert.pem -tls-key key.pem   # 用你自己的证书
```

- 自签证书覆盖本机的回环地址、私网地址与主机名；**地址变化（换 Wi-Fi、插网线）时会自动重签**，
  免得出现“昨天能用、今天提示证书不匹配”。重启不会换证书。
- 启动日志会打印证书路径与 SHA-256 指纹，请在设备上加信任时逐字比对：
  自签证书的信任动作如果没得比对，“装的是不是这台机器的证书”就只能靠猜。
- 首次访问需要信任：把 `<数据目录>/tls/server.crt` 传到手机/平板并安装为受信任根证书
  （iOS：设置 → 通用 → VPN 与设备管理 → 安装描述文件，再到“关于本机 → 证书信任设置”里启用；
  Android：设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书）。
- 启用加密且绑定非回环地址时**必须**提供配对码（`-pin`），否则拒绝启动：
  加密只解决“传输被看”，不解决“谁能进”。
- 自签证书是给内网用的。要对外提供服务，请在前面放一个真正的反向代理并申请正式证书。

### 第二屏（桌面端）

桌面壳默认只监听 loopback。要保留“手机/平板连 PC 游玩”，用 `-lan` 显式开启
（详见 [桌面端说明](DESKTOP.md)）：它会另起一个监听、强制配对码，并可与 `-tls auto` 叠加。

## 备份与剧情包

分享单个故事可导出 `.tavernpack`，包含分支、事件、模板和记忆，不包含密钥、进行中的草稿及未启用的导演讨论。导入分配新的会话/节点 ID，不覆盖原故事；损坏或与事件不一致的包会被拒绝。

完整备份应先用 Ctrl+C 正常退出，确认进程已结束，再复制整个数据目录（含 SQLite 的附属文件和配置）。不要只复制运行中的 `storage.db`。将备份存到受保护的位置；它可能含凭据和私人故事。

同一数据目录只允许一个进程打开。启动时会取得操作系统文件锁，并恢复中断的请求：完整结果重新校验提交，可恢复正文进入待续写，其余请求以 `PROCESS_INTERRUPTED` 失败并释放分支锁。重复恢复不应再次结算骰子或物品。正常退出请等待服务完成收尾；强制退出后先检查回合状态再重试。

## 删除故事与角色卡

**删除故事（不可撤销）**：在左栏「会话」列表里点某一行的删除按钮，按钮会变成「确认删除」，再点一次才真正删除；中途点「取消」即放弃。删除会一并清掉该故事的分支、回合、事件、快照、记忆与导演草稿，且没有回收站——需要留档就先导出 `.tavernpack` 或整目录备份。共享模板按内容寻址、可能被其它故事复用，因此不随会话删除。

删除的是当前正在读的故事时，界面会自动切到列表里的下一条；如果没有别的故事，就回到空白起始态（不会停在一个已不存在的故事上）。仍有回合在生成时服务端会拒绝（`SESSION_BUSY`），等它结束或先取消再删。

**移除角色卡**：在左栏「角色库」里点某张卡尾部的删除按钮，同样两步确认。这一步只把卡从浏览器本地的卡库移除——角色数据在建立故事时已写入服务端，因此已有存档不受影响，仍能正常打开与继续；只是该卡不再出现在卡库里，头像与角色标签回退为默认值。卡库清空后可随时点击「+ 导入 / 创建角色卡」重新载入。

## 升级与回退

1. 停止旧版，备份完整目录，记录 `-version`。
2. 解压新版到独立程序目录，使用原数据目录启动。数据库升级前自动创建一致性备份；迁移失败将回滚并明确报错。
3. 验证故事、分支和配置后再继续创作。升级后的数据库不能由旧版本打开。
4. 回退时停止新版，用升级前备份恢复到另一个数据目录，然后由旧版打开该目录。不要降低 `PRAGMA user_version`，也不要让旧程序直接写新版数据库。

历史事件不会静默重写。发现“快照与事件重放不一致”时保留原库与剧情包，在副本上定位不一致节点后提交脱敏复现；应用会拒绝导入不一致的剧情包，但不会静默重写已有故事。新版本修复了稀疏检查点重放中相邻节点排序的问题，但不自动替换旧版本可能已保存的不一致快照。

## 真实模型验收（100 例）

常规 CI 不调用付费模型；这一步在能连到评测网关的机器上手动执行（或走
`.github/workflows/model-eval.yml` 的手动触发）。额度**不可逆**，所以顺序是固定的：

```powershell
# 0) 先构建被测二进制（前端必须先 build：dist 被 //go:embed 嵌进二进制）
Set-Location web; pnpm install --frozen-lockfile; pnpm build; Set-Location ..
go build -o build/release-eval/tavernagent.exe ./cmd/tavernagent

# 1) 凭据只走环境变量（绝不写进仓库）
$env:TAVERNAGENT_EVAL_GATEWAY_KEY = "<网关密钥>"
$env:TAVERNAGENT_EVAL_TOKEN = "<被测实例使用的令牌>"
$env:TAVERNAGENT_EVAL_MODEL = "gemini-3.8-flash-high"   # 可选；默认值即此

python scripts/release_eval.py start                 # 起本地网关 + 隔离实例
python scripts/release_eval.py ledger                # 查余额（不可逆，先看清）
python scripts/release_eval.py preflight             # 内含预算闸：余额不足直接拒绝开始
python scripts/release_eval.py protocol --samples 5  # 先用小样本探路，确认协议与模型标签
python scripts/release_eval.py protocol --samples 100
```

- 报告落在 `output/release-readiness/gemini/`（不入库）。门槛：首过 ≥95、含一次修复 ≥99。
- `preflight` 会先读台账余额：不足 `samples + 修复余量` 就拒绝启动，避免跑到一半收到 429。
- 结论摘要请登记回 `docs/PROJECT_STATUS.md` §6（脱敏，只写数字与指纹，不写凭据）。

## 故障排查

| 提示或现象 | 处理 |
| --- | --- |
| 数据目录正在使用 | 停止使用该目录的另一进程，或选独立目录；不用删除锁文件来绕过锁 |
| 模型配置损坏 | 停止应用，保留损坏文件，恢复配置备份（`settings.json` / `settings.json.v1.bak`）；不要用空配置掩盖解析失败 |
| 删不掉某个连接 | 它仍被角色使用：按钮旁会写明是「对话生成 / 导演协商 / 后台记忆」哪一行在用，先去那一行换一条连接 |
| 供应商 401/429/5xx | 核对角色的连接、地址、密钥和供应商额度；失败与重试也可能计费 |
| 受理结果未知或断线 | 在原会话使用“重试”；客户端复用原幂等键，避免重复提交 |
| 正文等待续写 | 继续已保存草稿，或明确放弃；分支仍被该回合占用 |
| 分支或草稿冲突 | 重新读取最新进度并合并修改；旧工作线程不能覆盖新结果 |
| 请求过大 | 缩小角色卡、剧情包或 JSON 内容；API 返回 413 |
| 手机提示“连接不安全 / 证书不受信任” | 这是自签证书的正常首次状态：按上文把 `tls/server.crt` 装成受信任根证书，并核对启动日志里的 SHA-256 指纹 |
| 换网络后手机访问提示证书不匹配 | 证书会在下次启动时按新地址自动重签；重签后需要重新在设备上信任一次 |
| `-tls` 写错取值 | 启动直接失败并提示可用取值（off / auto / files）——这是刻意的，静默退回明文比启动失败危险得多 |
| 历史记忆翻页 | 页码绑定查询节点；切换搜索/分类会刷新到第一页 |
| 正在生成时刷新页面 | 会自动回到上次打开的故事并接着显示当前段落（含正在写的那一块）；若本地存储被禁用，则回退到列表第一条 |
| 退出时正在生成 | Ctrl+C 先取消在途生成并等待后台任务与请求收尾，再关闭数据库；日志出现“仍有在途请求未收尾”说明有请求超过等待上限，请附日志报告 |
| 想确认后台任务没有静默丢失 | 读 `GET /api/status`：`queueDropped` 是退出时丢弃的后台任务数（那一轮记忆抽取不会再补），`queueRejected` 是服务已开始退出后到达的任务数 |

报告问题时附版本、平台、脱敏配置与最小合成故事。不要公开 `data/`、`output/` 或原始网关日志。
