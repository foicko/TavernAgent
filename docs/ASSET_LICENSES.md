# 素材与授权

当前发布源文件与前端构建仅使用以下素材：

| 内容 | 来源 | 授权 |
| --- | --- | --- |
| `web/public/assets/original/*.svg` | 本项目新绘制的几何矢量插图与中性占位 | MIT，TavernAgent contributors |
| `web/src/lib/characterPresets.ts` 的中性占位皮肤与卡片模型定义 | 本项目代码与中性预设契约 | MIT |
| `scripts/fixtures/*.json` | 本项目合成测试数据 | MIT |
| 界面文字、CSS 与图标中的 Unicode 字符 | 本项目代码；由系统字体渲染 | 代码按 MIT；字体由用户系统提供，不随软件分发 |

项目不再从 Google Fonts 下载字体。发布包不包含外部角色卡、参考项目、论文、设计稿、用户存档、历史截图或不明来源 PNG。

旧的五张角色 PNG 和历史界面截图已从当前发布树移除；私人备份留在忽略目录。**已有 Git 历史仍可能含这些素材。** 本轮不重写用户历史。首次公开发布应从 `source-clean.zip` 建立干净仓库，或在获得全部历史素材授权后再公开原历史。不能仅凭当前文件删除就认定整个 Git 历史可公开。

用户自行导入的角色卡及生成内容不自动转让给项目。分享剧情包前请自行确认其中内容的公开权限。

第三方运行库的许可证见根目录 `THIRD_PARTY_NOTICES.md` 与 `LICENSES/`。
